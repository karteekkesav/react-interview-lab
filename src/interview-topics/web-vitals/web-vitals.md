# Web Vitals

## Interview Definition

Web Vitals are user-centered performance metrics that measure loading speed, responsiveness, and visual stability.

## Deep Explanation

Common Core Web Vitals include LCP for loading, INP for responsiveness, and CLS for layout stability. They help teams discuss performance in terms of user experience instead of only technical timing.

## Common Interview Questions

What is LCP?

Largest Contentful Paint measures when the main content appears.

What is INP?

Interaction to Next Paint measures responsiveness to user interactions.

What is CLS?

Cumulative Layout Shift measures unexpected layout movement.

## Common Mistakes

Only measuring local development.

Ignoring real-user field data.

Optimizing one metric while hurting usability.

## Best Practices

Measure in production.

Optimize images, JavaScript, and layout stability.

Use lab and field data together.
