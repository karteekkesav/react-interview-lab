# Next.js Concepts

## Interview Definition

Next.js is a React framework that adds routing, rendering strategies, server features, data fetching patterns, and production deployment conventions.

## Deep Explanation

React is the UI library. Next.js is a framework around React. Interviewers often expect you to explain routing, SSR, SSG, Server Components, Client Components, API routes or server functions, caching, and deployment.

## Example Used In This Folder

`NextjsConceptsExample.tsx` summarizes the major concept groups.

## Common Interview Questions

How is Next.js different from React?

React builds UI. Next.js provides app architecture around React.

What is a Client Component?

A component that runs in the browser and can use state, effects, and event handlers.

When use Next.js?

When you need routing, SEO, SSR/SSG, server data patterns, or full app framework features.

## Common Mistakes

Thinking Next.js replaces React.

Using Client Components everywhere by default.

Ignoring caching and revalidation behavior.

## Best Practices

Use framework routing conventions.

Keep interactivity in Client Components.

Understand rendering per route.
