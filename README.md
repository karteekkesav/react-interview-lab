# React Interview Lab

An interactive React and TypeScript interview-preparation workspace with runnable examples, concise revision notes, and topic-focused demonstrations.

## Included Topics

- React fundamentals, hooks, routing, forms, and state management
- Performance optimization and React 19 features
- TypeScript, testing, security, authentication, and API patterns
- TanStack Query, Tailwind CSS, micro-frontends, and architecture
- Runnable interview examples organized by topic

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router
- Redux Toolkit
- Auth0
- Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
```

Create a `.env.local` file when using Auth0:

```text
VITE_AUTH0_DOMAIN=your-domain
VITE_AUTH0_CLIENT_ID=your-client-id
```

## Validation

```bash
npm run lint
npm run build
```
